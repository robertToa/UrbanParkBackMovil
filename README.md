# Descripción del proyecto
UrbanPark es un proyecto de desarrollo de aplicaciones móviles orientado a la gestión de plazas de estacionamiento de una institución, permitiendo administrar su disponibilidad y ocupación.

Este repositorio contiene los componentes del backend necesarios para el funcionamiento de la aplicación móvil desarrollada en .NET MAUI, facilitando la comunicación y el intercambio de información mediante servicios web REST.

# Contenido del repositorio
- Backend: código fuente de los servicios web REST desarrollados en PHP.
- Backup: respaldo de la base de datos del proyecto.
- Scripts SQL: scripts para la creación de la estructura de la base de datos, incluyendo tablas, claves primarias y relaciones.
